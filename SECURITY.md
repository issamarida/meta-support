# Security Policy

SafeFrame handles sensitive footage of children. Please report vulnerabilities
privately to **issamaarida@gmail.com** rather than opening a public issue.

In scope, for example:

- uploads, previews or rendered videos reachable by anyone other than the uploader
- files that survive deletion (uploads, previews, analysis data, outputs)
- path traversal or arbitrary file read/write through the API
- ways to make the pipeline silently skip blurring

Please do not include real footage of people in reports. You will receive an
acknowledgement within 72 hours.
